n8n Workflow — Step by Step Setup Guide

Your Nova backend triggers n8n. n8n loads recipients from your API, saves them to Google Sheets, and sends Gmail to every recipient in one workflow run.

0How the whole flow works

This diagram shows where each system fits. Your backend never sends mail itself — it only forwards the trigger to n8n.

⚠️ Important: n8n Cloud cannot reach http://localhost:3000. The HTTP Request node must call a public API URL (deployed backend or an ngrok tunnel).

1Set up environment variables

Add these to Backend/.env. They are read by src/config/env.js and used in src/controllers/Webhook/proxy.controller.js.

N8N_USER=Nova
N8N_PASSWORD=your_webhook_password
N8N_MAIN_WEBHOOK=https://YOUR-N8N-HOST/webhook/YOUR-PATH-ID

Optional follow-up webhooks (fall back to the main URL if empty):

N8N_FOLLOWUP_1_WEBHOOK=
N8N_FOLLOWUP_2_WEBHOOK=
N8N_FOLLOWUP_3_WEBHOOK=
N8N_FOLLOWUP_4_WEBHOOK=
✅ Copy the Production URL (/webhook/...), never the test URL (/webhook-test/...). The test URL only works while the editor is listening.

2Prepare the Google Sheet

Create a spreadsheet with a tab named NOVA and these headers in row 1. Share it with the Google account used in n8n (Editor access).

campaignIdemailfull_nameworkMailactionsubjectbodystatussent_at

3Create the workflow and build the canvas

Open your n8n host → Create workflow → name it NOVA campaign send. Then add nodes in this order:

🟣 Node 1 — Webhook

  • HTTP Method: GET
  • Path: Fixed (UUID is fine)
  • Authentication: Basic Auth (N8N_USER / N8N_PASSWORD)
  • Respond: Immediately for testing, When Last Node Finishes later
GET {{ $json.query.campaignId }}
{{ $json.query.action }}
{{ $json.query.workMail }}

🟠 Node 2 — Switch (optional)

  • Value: {{ $json.query.action }}
  • Outputs: start_campaign, send_followup_1..4, stop_campaign
  • Build the start branch first
OutputEquals
startstart_campaign
follow1..4send_followup_1..4
stopstop_campaign

🔵 Node 3 — HTTP Request (load mails)

  • Method: GET
  • URL: public API + campaignId
  • Header: Authorization: Bearer 
GET https://PUBLIC-API/api/mails?campaignId={{ $('Webhook').item.json.query.campaignId }}

🟢 Node 4 — Split Out

  • Field to Split Out: data
  • Response: { "data": [ { "email", "full_name", ... } ] }
✅ One item per recipient — the engine for "send to everyone in one run".

💜 Node 5 — Edit Fields (Set)

NameExpression
campaignId{{ $('Webhook').item.json.query.campaignId }}
email{{ $json.email }}
full_name{{ $json.full_name }}
workMail{{ $('Webhook').item.json.query.workMail }}
action{{ $('Webhook').item.json.query.action }}
subject / bodycampaign copy
statusqueued

🌿 Node 6 — Google Sheets (Append)

  • Credential: Google Sheets OAuth2
  • Operation: Append Row
  • Document: spreadsheet ID
  • Sheet: NOVA
  • Map columns to the Set fields
✅ Split Out makes one row per user.

🟪 Node 7 — Split In Batches (recommended)

  • Batch size: 10
  • Optional Wait 2s between batches (Gmail limits)
  • Skip for 2–3 test emails

❤️ Node 8 — Gmail (Send)

  • Credential: Gmail OAuth2 for the workMail account
  • Operation: Send
  • To: {{ $json.email }}
  • Subject: {{ $json.subject }}
  • Message: {{ $json.body }}
✅ n8n runs this once per item = all recipients, one workflow.

🟡 Node 9 — Google Sheets Update (optional)

  • Match on email (and campaignId if possible)
  • status = sent
  • sent_at = {{ $now.toISO() }}

⚫ Node 10 — Save → Publish

Workflow must stay published for the production URL to work.

4Canvas summary (start branch)

Webhook (GET + Basic Auth) → Switch (action) start → HTTP GET /api/mails → Split Out (data) → Set → Google Sheets Append → Split In Batches → Gmail Send → Sheets Update status → loop batches stop / status → (no Gmail)

5Test from the Nova API

  1. Create a campaign: POST /api/campaigns/create (JWT)
  2. Add recipients: POST /api/mails/batch with campaignId and mails: [{ "email", "full_name" }]
  3. Sign in and copy the JWT
  4. Call the webhook:
POST http://localhost:3000/api/webhook
Authorization: Bearer 
Content-Type: application/json

{
  "campaignId": "1",
  "action": "start_campaign",
  "workMail": "you@gmail.com"
}

Webhook only published: { "success": true, "data": { "message": "Workflow was started" } }
Full workflow: check n8n Executions, the Google Sheet, and recipient inboxes.
